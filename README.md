# Shubham Murari - Personal Portfolio Website

A modern, responsive, high-performance personal portfolio website built with **React**, **Vite**, and **Tailwind CSS**.

## 🚀 Key Highlights & Features
- **Hero Section**: Personal introduction, dynamic status indicator, quick action buttons ("View Projects", "Contact Me"), and terminal preview card.
- **About Me**: Student-friendly background, 4 core learning pillars, quick overview stats, and interactive profile/resume preview modal.
- **Education**: Detailed timeline card for **B.Tech at JECRC University, Jaipur**, including core coursework focus and university environment highlights.
- **Skills**: Interactive skill cards with category filters for HTML, CSS, JavaScript, Python, Artificial Intelligence, Generative AI, Web Development, and Digital Productivity.
- **Projects**: Showcase cards with interactive modal previews for:
  1. Personal Portfolio Website
  2. AI Website Project
  3. Student Productivity Project
- **Achievements**: Extensible categorized showcase for Certifications, Hackathons, Courses, Awards, and Other Achievements.
- **Contact**: Professional contact section with 1-click email copy, direct LinkedIn link, and interactive contact message form.
- **Design**: Dark & light mode toggle, glassmorphic UI, responsive mobile hamburger drawer navigation, and smooth scrolling.

---

## 🛠️ Tech Stack
- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3.4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/) ready with `vercel.json`

---

## 💻 Local Development Setup

1. Open a terminal in the `portfolio` folder:
   ```bash
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173` in your browser.

---

## 📦 Production Build

To build the static files for production:
```bash
npm run build
```
The optimized production assets will be generated in the `dist/` directory.

To preview the production build locally:
```bash
npm run preview
```

---

## ☁️ Deploying to Vercel (1-Click)

1. Push your repository to **GitHub**.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Set the **Root Directory** to `portfolio` (if the repo root is parent) or leave default if repo root is the `portfolio` folder.
5. Framework Preset: **Vite**.
6. Click **Deploy**! 🚀
